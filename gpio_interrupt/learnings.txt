Probelms faced:
Overlay not loaded

Cause:
dtoverlay not applied.

Fix:
dtoverlay -l
dtc -I fs -O dts

Probe not called

Cause:
compatible mismatch.

Fix:
match OF table and DT node.

GPIO busy

Cause:
gpiomon consumer.

Fix:
release line owner.

Interrupt not firing

Cause:
button wiring issue.

Fix:
validated using gpiomon and direct GND shorting.

request_irq failure

Cause:
IRQ already allocated.

Fix:
free_irq lifecycle.

Sysfs leak

Cause:
probe failed after sysfs creation.

Fix:
cleanup in probe error path.

Wait queue crash

Cause:
character driver and platform driver used different private data structures.

Fix:
unify ownership and pass correct pointer through private_data.

Synchronization

Cause:
shared timestamp access.

Fix:
mutex protection.
